# 🌱 Plant Disease Prediction Project

This project is a **Plant Disease Detection System** built using **Convolutional Neural Networks (CNNs)** and deployed with **Streamlit** for an interactive web application.  
It helps in detecting plant diseases from images to support sustainable agriculture.

---

## 🚀 Steps to Run the Project

1. **Open Google Colab**  
   - Import or open the provided `.ipynb` file in Google Colab.

2. **Set Runtime to GPU**  
   - Go to `Runtime > Change runtime type > Select GPU` to speed up training.

3. **Run the Notebook**  
   - Select `Runtime > Run all` to execute the notebook cells.

4. **Model File Generation**  
   - After execution, a `.keras` file will be generated (trained model).

5. **Download Model**  
   - Place the generated `.keras` file inside the project directory.

6. **Install Required Packages**  
   - Run the following command to install dependencies:
     ```bash
     pip install tensorflow matplotlib opencv-python streamlit
     ```

7. **Run the Streamlit App**  
   - Open a terminal in the project directory and run:
     ```bash
     streamlit run app.py
     ```

8. **View the App**  
   - Congratulations 🎉 You can now view the project at:
     ```
     http://localhost:8501
     ```
